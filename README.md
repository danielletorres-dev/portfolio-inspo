# Portfolio Inspo

The link collection behind **danielletorres.com/inspiration**.

- `links.json` — the title and every post on the page. Newest date sorts first.
- `assets/` — the title image.
- `wall.css` — page styles (spacing, type sizes, colors).
- `wall.js` — the code that builds the page.
- `screenshots/` — website previews, taken automatically by GitHub whenever `links.json` changes.

The Cargo page reads `links.json` live, so editing it here updates the site within a few minutes.
